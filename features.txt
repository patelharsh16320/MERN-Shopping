━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- POST-PURCHASE ORDER REDIRECT
  After checkout user is now redirected to /orders/:id (order detail page)
  with a "🎉 Order Confirmed!" banner. Previously went to invoice page.

- ADMIN PAGE VISIBILITY CONTROL  [NEW]
  Admin toggles any customer page ON/OFF from /admin/pages.
  Inactive pages show 🚧 "Coming Soon" to users (live via Socket.io).
  Controllable: Home, Shop, Offers, Quiz, About, Contact, Support, Wishlist.
  Core pages (Cart, Checkout, Orders, Profile, Login) always visible.
  Files: server/models/PageSetting.js, server/routes/pageSettings.js,
         client/src/context/PageSettingContext.js,
         client/src/pages/admin/ManagePages.js, client/src/App.js

- SPECIAL OFFERS — LEFT FILTER SIDEBAR  [NEW]
  Filter panel on /offers page: search, sort (Highest Discount / Price /
  Ending Soon), discount chips (10%+ / 25%+ / 50%+ / 70%+), price range,
  offer-type chips (dynamic), In Stock Only toggle.
  Mobile: collapsible toggle button with active filter count.

- SPECIAL OFFERS — PRODUCT CARD REDESIGN  [NEW]
  New OfferCard component:
  • Image hover zoom + "👁 Quick View" overlay
  • Discount badge + Offer label badge
  • Wishlist ❤️/🤍 button (top-right)
  • Star rating + review count
  • Sale price / crossed-out original / "Save ₹X" pill
  • Countdown timer with styled unit boxes (hr : min : sec)
  • Low-stock progress bar (when stock < 10)
  • Quantity −/+ stepper
  • "✓ Added!" animated green confirmation on cart add
  • Skeleton shimmer loading placeholders
  • Out-of-stock dark overlay

- DASHBOARD LIVE STAT UPDATES  [ENHANCEMENT]
  Admin Dashboard updates in real-time via Socket.io:
  new_order → Orders+1 / Revenue+amount / Pending+1 / Recent Orders prepend
  new_user  → Users+1
  products_updated → product count refetch

- ADMIN PRODUCTS AUTO-REFRESH  [ENHANCEMENT]
  /admin/products listens for products_updated socket and auto-refetches list.

- CUSTOMER PRODUCTS PAGE AUTO-REFRESH  [ENHANCEMENT]
  /products page subscribes via initPublicSocket() to products_updated and
  calls fetchProducts() automatically — no browser reload.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- USER ADDRESS BOOK  [NEW]
  Separate UserAddress MongoDB collection (not embedded in User).
  Admin: view / add / edit / delete / set-default addresses per user.
  "📍 N" badge in Manage Users table opens AddressModal.
  User export/import automatically includes addresses.
  Seeded 140 dummy Indian addresses (4 per user) across 35 users.

- FULL DATABASE BACKUP & RESTORE  [NEW]
  One-click export all collections → full-backup-YYYY-MM-DD.json.
  Restore on any device — a-to-z data migration.
  Purple panel on Import/Export page. Collections: products, categories,
  users (+addresses), orders, invoices, coupons, analytics, contacts,
  subscribers, changelog, supportTickets.

- ORDER TRACKING IN CHAT WIDGET  [NEW]
  Chat now has 2 tabs: 💬 Chat + 📦 My Orders.
  My Orders shows: color-coded status badge, progress steps bar
  (Pending → Processing → Shipped → Delivered), item thumbnails,
  payment info. "📦 Track my orders" quick-button in empty chat.

- LIVE UNREAD MESSAGE BADGE  [NEW]
  Real-time +1/+2 counter on chat button (user & admin) via Socket.io.
  No page refresh. Badge persists via localStorage (chat_lastRead_{userId}).
  Pulse animation, 99+ cap. Badge shows even while popup is open.

- SOCKET.IO REAL-TIME FULL SITE  [NEW]
  Events:
    new_order          → admin_room  (badge + Dashboard + toast)
    products_updated   → public_room (Products + ManageProducts refresh)
    new_user           → admin_room  (Dashboard counter + toast)
    new_message        → user_{id}   (chat badge)
    page_settings_updated → public_room (live page toggle)
  Guest (unauthenticated) socket connections supported → public_room.

- BOT MESSAGE ON ORDER PLACEMENT  [NEW]
  After order placed, bot auto-sends:
  "🎉 Thank you {name}! Your order #{id} has been placed. Tap 📦 My Orders to track it!"
  Saved to ChatMessage DB + emitted via socket instantly to user.

- SCROLL BUTTONS MOVED  [FIX]
  ScrollButtons moved from right:82 to left:20 — no longer overlaps chat widget.
